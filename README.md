# ระบบลงเวลาละหมาดด้วยบัตรนักเรียน (RFID)

นักเรียนแตะบัตรที่เครื่อง ESP32 → ส่งไปที่ backend (Node.js + PostgreSQL) → ครูดูผลสด รายงาน และส่งออก Excel ผ่านเว็บ (React)

```
ESP32 + RC522  ──HTTP──▶  backend (Express + Prisma)  ──▶  PostgreSQL
 (แตะบัตร)                      │  ▲
                                │  └── REST API ◀── หน้าเว็บ React (ครู/แอดมิน)
                                └───── SSE (แตะบัตรแบบเรียลไทม์) ──▶ หน้าเว็บ
```

## โครงสร้างโปรเจค

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `database/schema.sql` | สคริปต์สร้างตารางทั้งหมด (PostgreSQL) |
| `docker-compose.yml` | PostgreSQL สำหรับพัฒนา (รันแล้วโหลด schema ให้อัตโนมัติ) |
| `backend/` | API: เข้าสู่ระบบ, นักเรียน/ห้อง/บัตร, อุปกรณ์, ตารางเวลาละหมาด, รับการแตะ, รายงาน, SSE |
| `frontend/` | หน้าเว็บ React + Vite (ภาษาไทย) |
| `firmware/esp32_rfid_tap/` | โค้ด Arduino สำหรับ ESP32 + RC522 พร้อมคิวออฟไลน์ |

## เริ่มใช้งาน (เครื่องพัฒนา)

ต้องมี Node.js 20+ และ Docker (หรือ PostgreSQL 14+ ที่ติดตั้งเอง)

### 1) ฐานข้อมูล

```bash
docker compose up -d
```

ถ้าไม่ใช้ Docker ให้สร้างฐานข้อมูลเองแล้วรัน `psql -f database/schema.sql <ชื่อฐานข้อมูล>`
และแก้ `DATABASE_URL` ใน `.env` ให้ตรงกัน

### 2) Backend

```bash
cd backend
cp .env.example .env
```

แก้ `.env` อย่างน้อย 3 อย่าง:

- `JWT_SECRET` — สร้างด้วย `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"`
- `PRAYER_LATITUDE` / `PRAYER_LONGITUDE` — พิกัดโรงเรียน (คลิกขวาใน Google Maps)
- `PRAYER_METHOD` — วิธีคำนวณเวลาละหมาด **ควรปรึกษาผู้รู้/คณะกรรมการอิสลามในพื้นที่ว่าใช้ตารางแบบไหน**
  (ค่าเริ่มต้นคือ `Singapore`) และ `PRAYERS` เลือกว่าจะลงเวลาละหมาดอะไรบ้าง

```bash
npm install
npx prisma generate      # สร้าง Prisma client (ต้องต่ออินเทอร์เน็ตเพื่อโหลด engine)
npm run seed             # สร้างบัญชีแอดมิน (ตั้ง SEED_DEMO=true เพื่อได้นักเรียนและอุปกรณ์ตัวอย่าง)
npm run dev              # เปิดที่ http://localhost:3000
```

ถ้าไม่ได้ตั้ง `ADMIN_PASSWORD` ตอน seed ระบบจะสุ่มรหัสผ่านและแสดง **ครั้งเดียว** ในหน้าจอ — เก็บไว้และเปลี่ยนหลังเข้าสู่ระบบ

### 3) Frontend

```bash
cd frontend
npm install
npm run dev              # เปิดที่ http://localhost:5173 (ส่งต่อ /api ไปที่ backend ให้อัตโนมัติ)
```

เข้าสู่ระบบด้วยบัญชีแอดมินจากขั้นตอน seed

### 4) ลองระบบโดยไม่ต้องมีอุปกรณ์

ถ้าตั้ง `SEED_DEMO=true` ตอน seed จะได้ API key ของอุปกรณ์ทดสอบและบัตรตัวอย่าง `AA000001`–`AA000005`

```bash
cd backend
npm run simulate -- <apiKey> AA000001
```

การแตะต้องเกิดขึ้น **ในช่วงเวลาละหมาด** (ดูที่เมนู "ตารางเวลาละหมาด") ไม่เช่นนั้นจะได้ผล `outside_window`
เปิดหน้า "ภาพรวมวันนี้" ค้างไว้ แล้วจะเห็นการแตะขึ้นสดทันที

## ใช้งานจริงตามลำดับนี้

1. เมนู **ห้องเรียน** → เพิ่มห้อง
2. เมนู **นักเรียน** → เพิ่มทีละคน หรือ "นำเข้าหลายคน" (วางจาก Excel: รหัส, ชื่อ, นามสกุล, เพศ)
3. เมนู **อุปกรณ์แตะบัตร** → เพิ่มอุปกรณ์ → เก็บ API key (แสดงครั้งเดียว)
4. อัปโหลดโค้ด ESP32 (หัวข้อถัดไป)
5. เมนู **ลงทะเบียนบัตร** → ให้นักเรียนแตะบัตรที่เครื่อง → เลือกชื่อเพื่อผูกบัตร
6. ตรวจเมนู **ตารางเวลาละหมาด** ว่าเวลาตรงกับที่โรงเรียนใช้ แก้รายวันได้
7. ใช้ **ภาพรวมวันนี้** ดูผลสด และลงให้เองได้ (มา/ลา/ขาด) สำหรับคนลืมบัตร และ **รายงาน** ส่งออก CSV ที่เปิดใน Excel ได้

## ESP32

### อุปกรณ์และการต่อสาย

| อุปกรณ์ | ขา ESP32 |
|---|---|
| RC522 SDA(SS) / SCK / MOSI / MISO / RST | GPIO 5 / 18 / 23 / 19 / 27 |
| RC522 3.3V, GND | 3V3, GND (**ห้ามต่อ 5V**) |
| DS3231 SDA / SCL (ไม่บังคับ) | GPIO 21 / 22 (ใช้ 3.3V) |
| บัซเซอร์แบบ Active | GPIO 25 |
| ไฟเขียว / ไฟแดง (ต่อผ่านตัวต้านทาน 220 Ω) | GPIO 26 / 33 |

### อัปโหลด

1. ติดตั้ง Arduino IDE + บอร์ด ESP32 (core 3.x)
2. ติดตั้งไลบรารี: **MFRC522** (miguelbalboa), **ArduinoJson** v7, **RTClib** (Adafruit, ถ้าใช้ DS3231)
3. ในโฟลเดอร์ `firmware/esp32_rfid_tap/` คัดลอก `config.example.h` เป็น `config.h` แล้วใส่ Wi-Fi, `SERVER_URL`, `API_KEY`
4. เลือกบอร์ด "ESP32 Dev Module" แล้วอัปโหลด เปิด Serial Monitor (115200) ดูสถานะ

เมื่อเน็ตหลุด เครื่องจะเก็บการแตะไว้ในแฟลชแล้วส่งย้อนหลังเองเมื่อกลับมาออนไลน์ (เวลาที่แตะจะถูกต้องก็ต่อเมื่อมี DS3231
หรือเคยตั้งเวลาจากเซิร์ฟเวอร์ไว้แล้ว)

## ความปลอดภัยและข้อควรระวัง

- **อย่านำ `docker-compose.yml` ที่มีรหัสผ่านตัวอย่างไปใช้บนเซิร์ฟเวอร์จริง** เปลี่ยนรหัสผ่านฐานข้อมูลและ `JWT_SECRET`
- API key ของอุปกรณ์เก็บในฐานข้อมูลแบบ hash หากทำหาย/รั่วให้กด "ออกคีย์ใหม่" ในหน้าอุปกรณ์
- ถ้า ESP32 ใช้ `http://` ในเครือข่ายโรงเรียน API key จะส่งแบบไม่เข้ารหัส — ใช้ HTTPS (reverse proxy เช่น nginx/Caddy) เมื่อผ่านเครือข่ายที่ไม่ไว้ใจ
  และให้เปิดหน้าเว็บผ่าน HTTPS เสมอเมื่อใช้งานจริง
- **การกันแตะแทนเพื่อน**: ระบบกันได้เฉพาะแตะซ้ำคนเดียวกัน บัตรของเพื่อนยังแตะแทนกันได้ ควรมีครูดูแลจุดแตะหรือติดกล้อง
  และครูลบรายการที่ผิดได้
- ข้อมูลนักเรียนเป็นข้อมูลส่วนบุคคล (PDPA) — จำกัดผู้ใช้งานที่ได้รับบัญชี และแจ้งวัตถุประสงค์การเก็บข้อมูลกับผู้ปกครอง
- เวลาในฐานข้อมูลเก็บเป็น UTC แสดงผลตาม `APP_TIMEZONE` (ค่าเริ่มต้น `Asia/Bangkok`)
  อย่าตั้ง timezone ของ PostgreSQL เป็น Asia/Bangkok

## เอกสาร API โดยย่อ

ทุกเส้นทางยกเว้น `/health` และ `/api/auth/login` ต้องส่ง `Authorization: Bearer <token>`

| เส้นทาง | หน้าที่ |
|---|---|
| `POST /api/auth/login` | เข้าสู่ระบบ → `{ token, user }` |
| `GET /api/attendance/dashboard?date=` | สรุปแต่ละช่วงละหมาดของวัน |
| `GET /api/attendance/missing?windowId=` | นักเรียนที่ยังไม่แตะ |
| `GET /api/attendance/summary?from=&to=` | สรุปรายคนช่วงวันที่ |
| `GET /api/attendance/export.csv?from=&to=` | ส่งออก CSV (เปิดใน Excel ได้) |
| `PUT /api/attendance/manual` | ครูลง/แก้สถานะเอง |
| `GET/POST /api/students`, `POST /api/students/bulk` | จัดการนักเรียน |
| `GET /api/cards/unassigned`, `POST /api/cards` | บัตรที่ยังไม่ผูก / ผูกบัตร |
| `GET/POST /api/prayer-windows`, `POST /api/prayer-windows/generate` | ตารางเวลาละหมาด |
| `GET /api/events?token=` | SSE แตะบัตรแบบเรียลไทม์ |
| `POST /api/device/taps` (`x-api-key`) | อุปกรณ์ส่งการแตะ |
| `POST /api/device/taps/batch` (`x-api-key`) | อุปกรณ์ส่งย้อนหลังเป็นชุด |
| `GET /api/device/ping` (`x-api-key`) | อุปกรณ์แจ้งออนไลน์ + รับเวลาเซิร์ฟเวอร์ |

## สถานะการตรวจสอบ

ตรวจแล้ว: `database/schema.sql` รันผ่านบน PostgreSQL 16, backend ผ่านการตรวจ syntax ทุกไฟล์,
frontend build ผ่านและทดสอบทุกหน้าในเบราว์เซอร์กับ API จำลอง

ยังไม่ได้ตรวจ: การรัน backend ร่วมกับฐานข้อมูลจริงผ่าน Prisma, การคอมไพล์/ทดสอบโค้ด ESP32 กับฮาร์ดแวร์
กรุณาทดสอบตามขั้นตอน "ลองระบบโดยไม่ต้องมีอุปกรณ์" ก่อนใช้งานจริง
